Import new skills

  1. Make a ZIP.

    Use a skills/ folder for agent-neutral skills. An all-skills/ archive can also contain shared-agents/, claude/, and kimi/ copies.

  2. Upload it to the inbox.

    Open the repository’s inbox/ folder, choose Add file → Upload files, and commit the ZIP to main.

  3. Let the importer rebuild everything.

    The action safely merges the archive, removes the ZIP, and updates this page, the README catalog, and manifest.json. Existing skills stay in place.
